## 考試資訊

- 日期：2026-10-08（四），IR335 電腦教室
- 形式：線上跑台，英文填充；30 分鐘內可重複作答取最高分，成績乘 1.25，80 分以上即滿分
- 範圍：背部、上肢、胸部、腹部（不含 intro）

### 作答規則

1. 沒有模糊比對，字要全部拼對才給分；字尾不要多打空格，否則算錯字
2. 血管、神經、韌帶、分支用縮寫：artery → a.、vein → v.、nerve → n.、ligament → lig.、branch → br.
3. 方向性用詞打全名，例如 anterior、posterior、external
4. 答案全部小寫，字首不要大寫
5. 一律用單數，字尾不加 (s)、不做變化

## 整理方法

- 資料來源：100 次作答紀錄，共 2,030 筆出現紀錄，去重後 200 張不同圖片、200 題
- 分類：保留四大分類（背部 14、上肢 88、胸部 40、腹部 58 題），每題另標局部區域
- 排序原則：
  - 以圖片的指認位置為準，同構造的不同圖片放在一起，局部相鄰的肌肉、神經、血管、韌帶交錯排列
  - 上肢由肩胛往手指（近端到遠端）；軀幹整體由上往下
  - 跨區的長構造優先維持局部連續，不硬拆到不同高度
  - 區域只是顯示標籤，不限制相鄰排列
- 每題顯示：圖片、正解、原題庫標題、出現紀錄（第幾次作答、題號）
- 驗證：200 題圖片雜湊、答案、大分類逐項對照原始資料，答案未改動；200 張圖片線上皆可載入
- Anki 版（`第一次線跑_分類題庫.apkg`）用同一套排序，新卡位置＝題號 001～200；檔案放在雲端硬碟 `二上/解剖/第一次線跑/題庫整理/`，不放在網站上
